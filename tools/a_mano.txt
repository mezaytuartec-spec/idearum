#
#  Aca van los audios que el cruce automatico NO puede resolver solo:
#
#    - dos pistas distintas con el mismo titulo ("Abrazame" de Jorge Vazquez y
#      "Abrazame" de Lulia Dumitrache): el nombre del archivo no alcanza para
#      saber cual es.
#    - el archivo se llama como otra cancion ("Tu que has venido a la Orilla"
#      es la pista "Tu que viniste a la Orilla").
#    - un mismo audio sirve para dos filas del Excel ("Sobreviviendo" y
#      "Sobreviviendo (con Coros)" son la misma grabacion).
#
#  Una por linea, con este formato:
#
#      nombre del archivo.mp3 = Titulo de la pista | Autor
#
#  El autor se puede dejar vacio si el titulo ya es unico. Las mayusculas, los
#  acentos del titulo y los espacios de mas no importan; el nombre del archivo
#  si: tiene que ser el de la carpeta de demos (los acentos cuentan, porque hay
#  archivos que solo se diferencian en eso).
#
#  Si una linea no se puede aplicar, previas.py avisa en pantalla y no inventa
#  nada. Para repetir un audio en dos pistas, escribi el archivo dos veces.
#
#  Despues de tocar esto hay que volver a correr:
#      python tools/previas.py "C:\ruta\a\los\demos"
#      python tools/csv_a_js.py Listado_2026_pistas.xlsx
# ============================================================================
